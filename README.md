# Guldkvistens Café - Frontend

Detta är framsidan för mitt bageriprojekt i kursen Backend-baserad webbutveckling. Sidan är byggd med Angular.

## Vad sidan gör:

- **Visar menyn:** Sidan hämtar automatiskt caféets bakverk från databasen och visar upp dem för besökaren.
- **Adminsida:** En låst sida där personalen kan logga in för att lägga till nya bullar, ändra priser eller ta bort bakverk.
- **Mobilanpassad:** Designen ändrar sig så att den ser bra ut både på datorn och på mobilen.

## Verktyg som har använts:

- **Angular** (för att bygga själva sidan och strukturen)
- **CSS** (för färger, typsnitt och bageri-designen)
